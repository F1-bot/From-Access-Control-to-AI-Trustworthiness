# Second-coder reliability study: crosswalk and ATLAS mitigation map

This folder holds the material for an independent second coding of the authors' mapping of requirement
units and ATLAS mitigations to the criteria. It was generated by `code/aitcert/make_second_coder.py`
(seed 0). The authors' mapping is **not** contained in anything that goes to the coder.

## Files

| File | For | Content |
|---|---|---|
| `to_coder/coding_sheet.csv` | coder | 107 blinded units: a stratified random sample of 69 of the 270 applicable crosswalk units (25.6 %; ceil(25 %) per framework: AI RMF 18/72, AI Act 11/44, ISO/IEC 42001 10/38, OWASP 3/10, CSF 2.0 27/106) and all 38 mapped ATLAS mitigations. Columns `item, id, framework, unit_text, candidate_targets` plus empty columns `coding, coder_flag, coded, notes`. |
| `to_coder/coder_instructions.md` | coder | Definitions of full / partial / none, coding rules, recording format, worked examples taken only from units outside the sample. |
| `to_coder/targets_glossary.csv` | coder | The 79 candidate targets (22 legacy services, 9 class-I services with level requirements, 27 legacy and 19 AI assurance rows, 2 profile mechanisms). ATLAS mitigations use the 77 targets without the profile mechanisms. |
| `sample_manifest.json` | administrator | Sample design, sampled ids, candidate lists, target groups, SHA-256 digest of the authors' mapping of the sampled units (not the mapping), software versions. |
| `score_second_coder.py` | administrator | Agreement statistics (see below). |
| `../../data/results/second_coder_reference_key.json` | administrator only | Frozen copy of the authors' mapping of the sampled units at preparation time. **Never send it to the coder.** |

## Procedure

1. Send only the folder `to_coder/` to the coder, with Appendix A of the article. For the legacy services the
   coder needs ND TZI 2.5-004-99 (Sections 6-9) or equivalent knowledge; for ISO/IEC 42001 and the OWASP Top 10
   for LLM Applications 2025 the coder needs the documents themselves (the sheet carries titles only).
   Do not send supplementary table S2, the specification files or the manuscript.
2. The coder fills `coding`, `coded` (and optionally `coder_flag`, `notes`) and returns
   `coding_sheet_<initials>.csv`. Excel files saved with `;` as the separator are accepted.
3. Score:

   ```
   python score_second_coder.py --selftest
   python score_second_coder.py --sheet coding_sheet_XY.csv --disagreements disagreements_XY.csv
   ```

   The script reads the authors' current mapping from `code/aitcert/spec/`. If the mapping of the sampled units
   has changed since the sheet was prepared (digest mismatch), it also reports agreement with the frozen key.
4. Report the independent agreement first; then resolve the disagreements (`disagreements_XY.csv`) by
   discussion, record the consensus mapping in the specification, and re-run `run_crosswalk.py`,
   `run_atlas_analysis.py` and `run_sensitivity.py`.

## Statistics computed by `score_second_coder.py`

- **Pair level**: each (unit, candidate target) pair is an item graded 0 (none), 1 (P) or 2 (F) by both coders
  (about 8,300 items). Cohen's kappa (unweighted, linear, quadratic), Krippendorff's alpha (nominal, ordinal,
  interval), observed agreement, the confusion matrix, and the positive specific agreement on which targets are
  credited at all. Because most pairs are "none" for both coders, read kappa and alpha together with the
  positive specific agreement.
- **Unit level**: the coverage score of each unit (best grade over the targets in X) for X_ext and X_leg,
  which is the quantity entering the coverage metrics. Weighted kappa and Krippendorff's alpha.
- **Coverage on the sample**: per framework, coverage (w = 0.5 and strict) computed from each coding and the
  difference with a bootstrap interval.
- 95 % intervals: percentile bootstrap over units, stratified by framework (B = 2000, seed 0).

Conventional reading (Krippendorff 2004): alpha >= 0.800 reliable; 0.667 <= alpha < 0.800 allows only tentative
conclusions.

The statistics were validated against published values (Krippendorff 2011 example: nominal 0.743, ordinal 0.815,
interval 0.849, ratio 0.797) and against scikit-learn's `cohen_kappa_score` (`--selftest`). The full scoring
pipeline was tested on simulated sheets (identical coding gives 1.000 for every statistic).

## Composition of the sample (authors' coding, for the record)

Of the 69 crosswalk units, 50 carry at least one target in the authors' mapping and 19 carry none
(AI RMF 13/18, AI Act 10/11, ISO/IEC 42001 9/10, OWASP 3/3, CSF 2.0 15/27); the 38 ATLAS mitigations are all
mapped. The sample contains 184 of the 431 grades of the two mappings.
